# How to Publish SentinelAI to GitHub

Follow these simple steps to publish your new project to your GitHub profile and showcase it on your resume!

---

### Step 1: Initialize Git Repository
Open PowerShell or your terminal inside the `SentinelAI` directory:
```bash
cd "c:\Users\gumma\OneDrive\ドキュメント\SentinelAI"
git init
git add .
git commit -m "feat: Initial commit of SentinelAI Autonomous SOC Analyst Platform"
```

---

### Step 2: Create a New Repository on GitHub
1. Go to [GitHub - New Repository](https://github.com/new).
2. Set **Repository name** to: `SentinelAI` (or `sentinel-ai`).
3. Set visibility to **Public** (so recruiters and hiring managers can view your code!).
4. Do **not** initialize with README, .gitignore, or license (we already created industry-standard ones for you).
5. Click **Create repository**.

---

### Step 3: Link and Push
Run the following commands (replace `YOUR-USERNAME` with your actual GitHub username):
```bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/SentinelAI.git
git push -u origin main
```

---

### Step 4: Add Topics / Tags to Your GitHub Repo
Once pushed, click the ⚙️ icon next to "About" on your repository page and add these tags to maximize recruiter visibility and GitHub search algorithm:
- `cybersecurity`
- `soc-analyst`
- `siem`
- `mitre-attack`
- `threat-intelligence`
- `ai-agent`
- `fastapi`
- `security-operations`
- `suricata`
- `sysmon`
- `incident-response`

---

### Step 5: Put It On Your Resume & LinkedIn!
Add the bullet points from the bottom of [`README.md`](file:///c:/Users/gumma/OneDrive/%E3%83%89%E3%82%AD%E3%83%A5%E3%83%A1%E3%83%B3%E3%83%88/Insta%20agent/SentinelAI/README.md) directly to your resume under **Projects** or **Technical Experience**.
